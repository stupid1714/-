# 스토어 주문처리 실습 프로그램

스마트스토어 기초과정 수강생(농업인)이 **상세페이지를 올린 뒤, 주문이 들어오면 무엇을 해야 하는지** 연습하는 프로그램입니다.
판매자센터 홈 화면(판매관리 · 정산관리 · 취소/반품/교환 · 판매지연 · 상품관리 · 리뷰현황)과 같은 구성으로 되어 있습니다.

> 교육용 연습 프로그램입니다. 실제 주문·결제·배송·정산은 일어나지 않고, 네이버와 관계없습니다.
> 수수료(5%), 반품배송비(왕복 6,000원), 자동 구매확정(배송완료 2일 뒤) 같은 값은 실습을 위해 정한 가상 값입니다.

## 배포 방법

**`스마트스토어_주문처리_실습.html` 파일 하나만** 나눠 주면 됩니다. (카카오톡·USB·이메일 모두 가능)

- 설치하거나 인터넷에 연결할 필요가 없습니다. 파일을 더블클릭하면 크롬·엣지 같은 인터넷 브라우저에서 열립니다.
- 실습 기록은 각자 컴퓨터 브라우저에 자동 저장되어, 껐다 켜도 이어서 할 수 있습니다.
- 처음부터 다시 하려면 오른쪽 위 **[처음부터]** 를 누릅니다.
- **PC와 휴대폰 모두 지원합니다.** 같은 파일이 화면 크기에 맞춰 자동으로 바뀝니다.

### 휴대폰 화면

판매자는 실제로 휴대폰으로 주문을 처리하는 경우가 많아서, 휴대폰에서도 모든 업무를 할 수 있게 만들었습니다.

- **아래쪽 탭:** 🏠 홈 · 📦 발주/발송 · ↩️ 취소·반품 · ⭐ 리뷰 · ☰ 전체메뉴 (처리할 건수가 빨간 숫자로 표시)
- **주문 목록은 카드 모양**으로 보여 주고, 위에 **전체 선택**이 있습니다. 버튼은 손가락으로 누르기 쉽게 크게 만들었습니다.
- 확인 창은 화면 아래에서 올라옵니다.
- 구매자 전화번호를 누르면 **바로 전화를 걸 수 있습니다** (실습 번호라 실제로 걸지는 마세요).
- 글자 크게와 처음부터 다시 하기는 **☰ 전체메뉴 → 설정**에 있습니다.

> **휴대폰으로 나눠 줄 때:** 카카오톡으로 받은 HTML 파일은 휴대폰 기종에 따라 열리지 않거나 저장이 안 될 수 있습니다.
> 휴대폰 실습은 이 파일을 **인터넷 주소(링크)로 올려서** 주소를 나눠 주는 방법이 가장 확실합니다.
> 링크를 크롬이나 사파리로 열고 **"홈 화면에 추가"** 를 하면 앱처럼 아이콘이 생깁니다.

## 화면 구성

| 위치 | 하는 일 |
| --- | --- |
| **홈 (대시보드)** | 판매자센터 홈과 같은 숫자 카드. 숫자를 누르면 해당 목록으로 이동. 맨 위 **✅ 오늘 할 일**에 지금 처리할 일이 순서대로 나옴 |
| **📅 다음날로 ⏭** (위쪽) | 하루가 지나감 → 배송완료, 반품·교환 상품 수거완료, 구매확정, 정산 입금, 발송기한 페널티가 진행됨 |
| **🧑‍🌾 손님 역할** (오른쪽 아래) | 강사·수강생이 손님이 되어 상황을 만드는 버튼: 새 주문, 취소요청, 반품요청, 교환요청, 구매확정, 좋은/나쁜 리뷰, 발송기한 지난 주문, **바쁜 하루(종합 실습)** |
| **🎯 실습 미션** | 13단계 미션. **[연습 상황 만들기]** 를 누르면 필요한 주문이 생기고, 해내면 자동으로 ✔ 표시 |
| **📖 용어 풀이** | 발주확인, 송장번호, 구매확정, 정산, 귀책사유, 페널티 등을 쉬운 말로 설명 |
| **글자 크게** | 글자를 크게 키움 |

## 연습할 수 있는 업무

1. **주문 → 발주확인 → 발송처리** – 신규주문을 체크하고 발주확인, 택배사 선택 + 송장번호 입력 후 발송처리 (연습용 송장번호 [자동] 버튼, 직접전달 선택 가능)
2. **배송조회 · 배송완료 · 구매확정 · 정산** – 구매확정 다음날 수수료를 뺀 금액이 비즈월렛으로 입금
3. **취소요청** – 보내기 전이면 [취소승인](환불·재고 복구), 이미 보냈으면 [취소거부·발송처리]
4. **반품** – 수거요청 → (다음날) 수거완료 → 상품 확인 후 반품완료(환불). 구매자 사정이면 반품배송비를 환불금에서 빼고, 판매자 책임이면 판매자가 부담. 정당한 사유가 있을 때의 반품거부
5. **교환** – 수거요청 → 수거완료 → 송장번호 넣고 교환 재배송 → (다음날) 교환완료
6. **판매지연** – 발송기한(주문 후 3일)이 지나면 페널티. 기한 전에 발송지연 안내(사유 + 새 발송예정일)
7. **판매취소** – 재고 부족 등으로 판매자가 먼저 취소 (페널티 안내)
8. **리뷰** – 답글 달기(별점별 **답글 예시** 제공), 포인트(혜택) 지급(정산금에서 차감), 베스트 리뷰 선정, 리뷰 이벤트 만들고 당첨자 발표
9. **상품관리** – 재고·가격 수정, 품절/판매 재개 (재고 0이면 자동 품절)

## 수업 진행 예시

1. 처음 열면 나오는 안내에서 수강생이 **자기 농장 이름**을 입력합니다.
2. **🎯 실습 미션** 1번부터 함께 따라 합니다. 각 미션의 [연습 상황 만들기]를 누르면 바로 연습할 수 있습니다.
3. 모든 미션을 마치면 **🧑‍🌾 손님 역할 → 🔥 바쁜 하루 시작하기** 를 눌러 주문 5건·취소·반품·교환·리뷰·지연이 한꺼번에 들어온 상황을 **오늘 할 일** 목록을 보며 혼자 처리해 봅니다.
4. 더 연습하려면 손님 역할 패널의 "[다음날로] 누를 때마다 손님 주문·요청이 자동으로 들어오게 하기"를 켭니다.
