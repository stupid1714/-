# 학습 관리 웹사이트

관리자 · 선생님 · 학생 · 학부모가 각자 로그인해서 진도, 과제, 자료, 코멘트, 출석을 확인하는 웹사이트입니다.
PC 브라우저와 휴대폰 모두에서 쓸 수 있고, 휴대폰에서는 **홈 화면에 추가**하면 앱처럼 실행됩니다(PWA).

## 화면별 기능

| 역할 | 할 수 있는 일 |
| --- | --- |
| **학생** | 내 이름·진도율·현재/다음 진도·과제·수업 요일과 시간 확인, 진도에 맞춰 실습 파일 업로드(본인 파일 삭제 가능), 선생님 자료 다운로드, 코멘트·출석·진도 기록(사진 포함) 보기 |
| **학부모** | **💬 선생님께 메시지 보내기·답장 받기**, 우리 아이의 진도·과제·수업 요일과 시간·선생님 코멘트·출석 현황·진도 기록(사진 포함) 보기, 아이가 제출한 실습 파일 다운로드 |
| **관리자** | 선생님이 하는 일 전부 + **선생님 계정 만들기·수정·삭제**, **회원가입 승인/거절**, 학생 삭제 |
| **선생님** | **💬 메시지함**(학부모 메시지 확인·답장, 안 읽은 수 표시), 학생 목록(오늘 출석·진도율이 한눈에 보임, 이름 검색), 학생을 누르면 진도·과제·다음 진도·메모 편집, 학생별 자료 업로드와 제출물 확인, 코멘트 작성, 학생별 수업 요일·시간 설정(요일마다 시간이 달라도 됨), 주간 시간표, 오늘 오는 학생만 보기, 출석 체크(출석/지각/결석/공결), **진도 기록(여러 줄 글 + 그날 사진 최대 10장, 수정 가능)**, 계정 관리(학생·학부모 계정 생성, 비밀번호 재설정, 삭제), 전체 학생 공통 자료 업로드 |

- 학생은 자기 정보만, 학부모는 연결된 자녀 정보만 볼 수 있도록 서버에서 권한을 검사합니다.
- "선생님 메모"는 선생님에게만 보입니다.
- 학부모 메시지는 그 학생의 학부모와 선생님·관리자만 볼 수 있습니다(학생에게는 보이지 않음). 상대방이 읽었는지 '읽음/안 읽음'으로 표시됩니다.
- **📄 학습 리포트 PDF:** 학생 화면 위쪽의 버튼으로 진도·교재 진도(체크한 항목과 날짜)·진도 기록(사진 포함)·코멘트·출석·과제를 A4 PDF로 내려받습니다.
  - 기간(최근 1·3·6개월, 전체, 직접 지정)과 넣을 내용을 고를 수 있습니다.
  - 선생님·관리자는 **선생님 메모**도 넣을 수 있습니다(학부모님께 보낼 때는 체크를 빼세요). 학생·학부모가 내려받는 PDF에는 메모가 들어가지 않습니다.
  - 인터넷 연결 없이 동작합니다(PDF 도구 `public/vendor/html2pdf.bundle.min.js`, MIT 라이선스 포함).
- 모든 계정은 오른쪽 위 **비밀번호** 버튼으로 비밀번호를 바꿀 수 있습니다.

## 회원가입과 계정

- **학생·학부모**는 로그인 화면의 **회원가입**으로 직접 가입합니다. 가입 후 **관리자가 승인**해야 로그인할 수 있습니다.
  - 학부모는 가입할 때 **자녀 이름 + 자녀의 학생 아이디**를 입력해서 자녀와 연결합니다. 그래서 자녀가 먼저 학생으로 가입해야 합니다.
  - 엄마·아빠가 각각 학부모 계정을 가질 수 있습니다.
- **선생님 계정은 회원가입이 없고**, 관리자가 **🧑‍🏫 선생님 관리**에서 아이디를 만들어 줍니다. 권한을 '관리자'로 주면 관리자 메뉴도 쓸 수 있습니다.
- 선생님·관리자는 **+ 학생 추가**에서 **이름만 넣어도** 학생을 등록할 수 있습니다. 학생·학부모 아이디와 비밀번호는 그때 넣어도 되고, 나중에 학생 화면의 **계정** 탭에서 언제든 만들 수 있습니다(승인 불필요).
  - 비밀번호를 비워 두면 6자리 숫자로 자동 생성됩니다.
- 학생마다 **담당 선생님**을 정할 수 있고, 선생님은 **내 담당 학생만 보기**로 자기 학생만 볼 수 있습니다.
- **👥 계정 목록**에서 학생·학부모의 아이디와 **선생님이 정해 준 비밀번호**를 확인할 수 있습니다.
  - 학생·학부모가 직접 바꾼 비밀번호(또는 회원가입 때 직접 정한 비밀번호)는 보이지 않습니다. 잊었다면 **임시 비밀번호**를 발급해 안내 문구를 복사해서 보내 줍니다.

## 교재 목차로 진도 관리

- **📚 교재·목차**에 교재별 목차가 과목별로 들어 있습니다(`server/seed/curriculum.json`).
  - **파이썬:** 으뜸파이썬(예제 222개)·두근두근파이썬(예제 195개)·자기주도파이썬(19장), 공통 단계 1~25 (원본: 진도 정리 엑셀)
  - **C언어:** C언어 Express(380항목, 절·LAB + 예제 파일)·C언어 마스터(**예제 234개**, 예제 파일 기준)·자기주도 C언어 프로그래밍(19장), 공통 단계 1~22
    - Express: 절·LAB·Mini Project를 항목으로 넣고 Q&A·Summary·Exercise·Programming·찾아보기·부록은 뺐습니다.
      1~17장 예제 파일을 모두 반영했습니다. 해당 항목에 파일명을 붙이고, 맞는 항목이 없는 예제는 그 절 바로 뒤에 추가했습니다(380항목).
      목차가 바뀌어도 이미 체크한 기록은 그대로 유지됩니다.
    - C언어 마스터: 예제 파일 242개 중 여러 파일로 된 예제는 하나로 묶고(헤더 파일 포함), 거의 같은 사본 2개(struct_argument_1·2)는 뺐습니다. 파일에 제목이 없어 코드 내용을 보고 제목을 붙였으니, 책과 다르면 교재·목차에서 고쳐 쓰세요.
  - 기본 교재의 목차가 새 버전으로 바뀌면(예: 절 단위 → 예제 단위) 체크 기록이 없을 때만 바꾸고, 이미 체크한 학생이 있으면 기존 교재는 두고 '(예제)' 교재를 따로 추가합니다.
  - 새 버전에 기본 교재가 추가되면 서버를 켤 때 자동으로 들어갑니다. 관리자가 지운 기본 교재는 다시 생기지 않습니다.
- 과목마다 공통 단계표가 따로 있고, 같은 과목 교재끼리 단계별 진행률을 합쳐서 보여 줍니다.
- 학생 화면의 **📚 교재 진도** 탭에서 교재를 지정하고(여러 권 가능), 수업한 예제를 체크하면
  - **진도율** = 완료한 항목 수 ÷ 지정한 교재 전체 항목 수 (여러 권이면 합쳐서 계산)
  - **현재 진도** = 마지막으로 체크한 항목, **다음 진도** = 그다음 항목
  이 자동으로 바뀝니다. 체크한 날짜가 함께 저장되고, '장 전체 완료' 버튼으로 한 장을 한 번에 체크할 수 있습니다.
- 단계별(1~25)·구간별(기초·중급·심화) 진행률도 자동으로 보여 줍니다. 학생·학부모 화면에도 같은 내용이 보입니다(읽기 전용).
- 교재를 지정하지 않은 학생은 예전처럼 슬라이드바로 진도율을 정합니다.
- 관리자는 새 교재를 추가할 수 있습니다. 엑셀에서 **머리글 줄부터 표를 복사해 붙여넣거나**, 한 줄에 하나씩(`#`로 시작하는 줄은 장 이름) 입력하면 됩니다.

## 수업 시간 규칙

- 주 2회, 1회 수업은 1시간 30분입니다. 평일은 시작 시간만 고르면 끝나는 시간이 자동으로 채워집니다.
- 토요일반은 09:00~12:00에 2회분을 한 번에 진행합니다 (**토요일반으로 설정** 버튼).
- 수업 시간 길이로 횟수를 계산합니다(1시간 30분 = 1회, 3시간 = 2회분). 합계가 주 2회가 아니면 목록에 표시되고, 저장할 때 한 번 더 확인합니다.
- 규칙을 바꾸려면 `public/app.js` 위쪽의 `CLASS_MINUTES`, `WEEKLY_SESSIONS`, `SATURDAY_SLOT` 값을 고치면 됩니다.

## 실행 방법

Node.js **22.13 이상**이 필요합니다(내장 SQLite 사용, 별도 DB 설치 불필요).

**Windows:** 프로그램 폴더의 **`실행하기.bat`** 을 더블클릭하면 설치·실행·브라우저 열기까지 자동으로 됩니다.

직접 명령어로 실행하려면 프로그램 폴더에서:

```bash
npm install
npm start
```

브라우저에서 http://localhost:3000 으로 접속합니다.

### 휴대폰에서 보기 (같은 와이파이)

1. 서버를 켜면 검은 창에 `★ http://192.168.x.x:3000` 처럼 휴대폰용 주소가 나옵니다.
2. 처음 한 번은 **`휴대폰접속허용.bat`** 을 더블클릭해서 Windows 방화벽을 허용합니다(관리자 확인 창에서 [예]).
3. PC와 **같은 와이파이**에 연결한 휴대폰 브라우저에 ★ 주소를 입력합니다.

### 휴대폰 LTE·다른 와이파이에서 보기 (임시 인터넷 주소)

같은 와이파이에서 안 열리면(공유기가 기기끼리 연결을 막은 경우 등) **`인터넷주소만들기.bat`** 을 더블클릭하세요.
Cloudflare 무료 터널로 `https://○○○.trycloudflare.com` 주소가 만들어져 어디서나 열립니다.

- 처음 한 번 터널 프로그램(cloudflared.exe)을 자동으로 내려받습니다.
- 창을 닫으면 주소가 사라지고, 다시 실행하면 주소가 바뀝니다.
- 주소를 아는 사람은 누구나 로그인 화면에 들어올 수 있으니 **기본 비밀번호를 꼭 바꾸세요** (기본 비밀번호를 쓰는 동안 화면 위에 노란 경고가 뜹니다).

### 처음 제공되는 테스트 계정

| 역할 | 아이디 | 비밀번호 |
| --- | --- | --- |
| 관리자 | `admin` | `admin1234` |
| 선생님 | `teacher1` | `1234` |
| 학생 | `student1`, `student2` | `1234` |
| 학부모 | `parent1`(student1의 부모), `parent2` | `1234` |

> ⚠️ 실제로 쓰기 전에 반드시 선생님 비밀번호를 바꾸고, 테스트 학생은 삭제하세요.

### 환경 변수

| 이름 | 기본값 | 설명 |
| --- | --- | --- |
| `PORT` | `3000` | 서버 포트 |

## 휴대폰에서 앱처럼 쓰기

1. 서버를 인터넷에서 접속 가능한 곳(예: Render, Railway, Fly.io, 개인 서버)에 올리고 **HTTPS** 주소를 연결합니다.
2. 휴대폰 브라우저로 접속합니다.
   - 아이폰(Safari): 공유 버튼 → **홈 화면에 추가**
   - 안드로이드(Chrome): 메뉴 → **앱 설치** 또는 **홈 화면에 추가**

배포할 때는 `DATA_DIR`이 서버를 재시작해도 지워지지 않는 디스크(볼륨)를 가리키게 해야 데이터와 파일이 유지됩니다.

## 폴더 구조

```
server/
  index.js   API 서버 (로그인, 권한, 파일 업로드/다운로드)
  db.js      SQLite 테이블 정의, 테스트 계정 생성
public/
  index.html, app.js, app.css   화면 (PC·모바일 반응형)
  report.js  학습 리포트 PDF 만들기
  vendor/    PDF 도구 (html2pdf.js)
  manifest.webmanifest, sw.js, icon.svg   홈 화면 앱(PWA) 설정
data/        (실행 시 생성) academy.db, uploads/
```
